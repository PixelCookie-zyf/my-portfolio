# Fonts

Self-hosted copies of the Google Fonts latin subsets (variable `.woff2` files), loaded with
`next/font/local` in [`../layout.tsx`](../layout.tsx).

| File | Family | Licence |
| --- | --- | --- |
| `inter-latin.woff2` | [Inter](https://github.com/rsms/inter) | [OFL 1.1](./OFL-inter.txt) |
| `fraunces-latin.woff2`, `fraunces-italic-latin.woff2` | [Fraunces](https://github.com/undercasetype/Fraunces) | [OFL 1.1](./OFL-fraunces.txt) |
| `caveat-latin.woff2` | [Caveat](https://github.com/googlefonts/caveat) | [OFL 1.1](./OFL-caveat.txt) |
| `fredoka-latin.woff2` | [Fredoka](https://github.com/hafontia/Fredoka-One) | [OFL 1.1](./OFL-fredoka.txt) |
